# 개인 프로필·pose 비교 UI 검증 기록

2026-08-20에 iPhone 폭 375×812에서 홈과 개인 프로필 화면을 확인했다. 홈은 기존 원본 GitHub 제품 언어인 오렌지·네이비·흰 블록 카드·3단계 흐름을 유지했고, `MY PROFILE`은 독립적인 개인 데이터 화면으로 진입한다.

| 화면 | 확인 결과 |
| --- | --- |
| 홈 | 업로드 블록이 1열로 전환되고, Side 동영상 선택 뒤 동기 비교와 pose detection 제어가 나타남 |
| 개인 프로필(비로그인) | 로그인·회원가입 진입만 노출되고, 스켈레톤·원본 영상 데이터는 표시·저장하지 않음 |
| 개인 프로필(로그인 후 설계) | OAuth 세션에 한정된 이름·압축 pose 후보·품질 보고서만 저장하며, 삭제 제어를 제공함 |

이 확인은 화면 밀도와 비로그인 경계를 대상으로 한다. 실제 iPhone 네이티브 MediaPipe detector는 `MediaPipeTasksVision`을 포함한 custom development build에서 별도로 기기 검증해야 한다.
