# 생성형 3D 참조 전량 폐기 검증

2026-08-20에 iPhone 폭 375×812에서 홈과 라이브러리 화면을 확인했다.

| 확인 항목 | 결과 |
| --- | --- |
| 기존 16개 생성형 3D 모션 | 활성 라이브러리·추천·순위·뷰어에서 제거됨 |
| 홈 제목·흐름 | `실제 영상으로 다시 구축한다`, Capture → Verify → Build로 변경됨 |
| 라이브러리 | `0 APPROVED REAL-VIDEO 3D MODELS`와 생성형 pose·추정 관절 경로 제외 상태를 표시함 |
| 사용자 pose | 업로드 영상의 개인 단일 시점 pose 후보 경로는 유지하되 실제 선수 3D와 분리됨 |

현재 3D 라이브러리가 비어 있는 것은 오류가 아니라 검증되지 않은 생성형 모션을 제품에 노출하지 않기 위한 의도된 상태다.
