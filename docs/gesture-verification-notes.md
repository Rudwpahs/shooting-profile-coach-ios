# 3D 스켈레톤 제스처 검증 기록

## 적용 내용

드래그 중 발생하던 모든 이동 이벤트의 즉시 렌더링을 `requestAnimationFrame` 단위 카메라 갱신으로 묶었다. 한 손가락의 가로 드래그는 회전을, 두 손가락 핀치는 78%~165% 범위의 확대·축소를 담당한다. 세로 드래그는 부모 스크롤 뷰가 계속 처리하도록 분리했다.

| 검증 항목 | 결과 |
| --- | --- |
| iPhone 카드 배치 | 줌 축소·현재 배율·확대·초기화 제어가 375px 폭에 한 줄로 표시됨 |
| 핀치 경계 | 투영 배율이 78% 미만 또는 165% 초과로 이동하지 않음 |
| 드래그 경계 | 시점 회전은 -90°~90° 범위를 유지함 |
| 회귀 테스트 | 3D 포즈 테스트 4개, 추천 테스트 4개 통과; 인증 테스트 1개 스킵 |

## 사용 안내

카드 위에서 좌우로 드래그하면 시점이 회전하고, 두 손가락 핀치 또는 `−`·`＋` 버튼으로 확대·축소한다. `RESET`은 사선 100% 뷰로 되돌린다.
