# 익명 슈팅 3D 참조 애니메이션 재구성 명세

## 감사 결론

기존 16개 모델은 **프레임 단위 3D 캡처가 아니었다**. 각 영상의 소수 집계 관절각을 16명 내부의 최소·최대값으로 정규화한 뒤, 이를 일반적인 뼈대에 적용한 결과였다. 이 방식은 최솟값·최댓값 모델에 0·100의 극단값을 강제하며, 실제 슈팅 순서·좌표계·개인별 관절 경로를 보존하지 못한다. 따라서 기존 데이터를 `선수 3D 모델` 또는 `카메라 상대 3D 시퀀스`로 취급하지 않는다.

| 감사 항목 | 결과 | 제품 조치 |
| --- | --- | --- |
| 원본 영상 16개 | 연속 프레임 pose를 바로 사용할 수 있는 영상은 없음 | 원본 프레임 모션 사용 금지 |
| 영상 검토 | 10개는 수동 클립 분리가 필요하고, 6개는 연속 전신 시퀀스에 부적합 | 모델별 영상 적합성 상태 보존 |
| 캘리브레이션 | 없음 | metric 3D·정확한 관절 각도·개인 체형 추정 주장 금지 |
| 기존 특성 | 표본 내 min-max 정규화로 0·100 극단값 발생 | 고정·보수 범위의 상대 특성으로 재생성 |
| 앱 뷰어 | 관절 특성에서 만든 일반 뼈대 | 생체역학적 **참조 애니메이션**으로 재명명 |

## 재구성 원칙

새 모션은 영상 프레임을 복제하지 않는다. 익명 16개 프로필의 요약 관절 지표는 **표현 폭을 조절하는 약한 상대 특성**으로만 사용한다. 모든 모델은 준비 → 딥 → 상승 → 릴리스 → 팔로우스루라는 연속적 점프슛 모션을 공유하며, 각 단계의 상대 위치 관계와 프레임 간 변화량을 품질 게이트로 검증한다.

> 검증된 3D 연구는 다수 카메라와 동기화된 고속 캡처를 사용해 관절 데이터를 얻는다. 본 앱의 영상 요약값은 그 수준의 좌표계·시간 정렬·정확도를 제공하지 않으므로, 본 애니메이션은 시각적·교육적 참조물이다. [1]

농구 점프슛의 합리적 참조 모션은 준비 구간의 하체 굴곡, 딥 이후의 하체 신전·상승, 릴리스 시 상승한 손목과 팔 확장, 그리고 릴리스 이후의 연속적 팔로우스루를 포함해야 한다. 거리 증가 시 더 큰 무릎·고관절 굴곡과 낮은 팔꿈치 위치가 관찰될 수 있으나, 이를 특정 개인의 정답 관절각으로 해석하지 않는다. [2] [3]

## 품질 게이트

| 게이트 | 통과 조건 | 실패 시 조치 |

| 단계 순서 | 다섯 단계가 준비·딥·상승·릴리스·팔로우스루 순서로 존재 | 렌더링 차단 |
| 하체 연결 | 딥의 골반 높이가 준비보다 낮고, 상승의 골반 높이가 딥보다 높음 | 모션 재생성 |
| 릴리스 | 릴리스 손목이 어깨보다 높고, 슈팅 팔이 준비보다 더 확장됨 | 모션 재생성 |
| 연속성 | 인접 프레임의 어느 관절도 비현실적으로 순간 이동하지 않음 | 파라미터 제한 |
| 근거 경계 | `summary_derived_biomechanical_reference_animation` 상태와 영상 적합성 상태가 노출됨 | 라이브러리 공개 차단 |
