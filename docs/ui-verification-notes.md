# 원본 GitHub UI 복원 검증 기록

원본 `static/index.html`과 `styles.css`를 기준으로, 웹 미리보기의 데스크톱(1280px) 및 iPhone 폭(375px) 화면을 점검했다.

| 검증 항목 | 확인 결과 |
| --- | --- |
| 배경 | 오렌지 워시, 세로 코트 라인, 우측 녹색 글로우를 적용했다. |
| 타이포그래피 | Barlow 및 Barlow Condensed 번들 글꼴을 포함했다. |
| 페이지 구조 | Hero, 3단계 진행 표시, 업로드 블록, 스코어보드, skeleton-canvas, 유사 모션 목록의 단일 스크롤 구조를 적용했다. |
| 모바일 | 업로드·진행 단계·스코어보드가 1열로 전환되며, 히어로 제목은 iPhone 폭에 맞춰 축소했다. |
| 추천 기준 | 목표 하나가 즉시 점수 목표·스타일 매핑·순위에 반영되고, 적용 문구를 화면에 노출한다. |

정적 웹 번들을 다시 생성한 뒤 iPhone 폭을 재점검했다. 히어로는 두 행으로 유지되고, 진행 단계와 업로드 블록은 원본의 모바일 1열 구성을 따른다. 추천 회귀 테스트는 거리와 릴리스 목표가 서로 다른 최상위 모션을 선택하는 것을 확인한다.
