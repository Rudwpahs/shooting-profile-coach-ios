# Shooting Analysis Center 기반 Curry qualitative shooting profile

Shooting Analysis Center 채널의 Stephen Curry 메커니즘 분석 01–04는 4개의 공개 편집 영상으로 구성되어 있다. 이 자료는 **qualitative form trait**를 정의하는 evidence로는 활용할 수 있지만, 동일 shot의 synchronized calibrated camera pair나 metric 3D motion source는 제공하지 않는다.

| 메커니즘 축 | 4부 시리즈에서 반복된 관찰 | 제품에 허용되는 표현 |
| --- | --- | --- |
| Base | 오른손 shooter의 turn stance와 shooting-side knee–elbow–eye alignment | `turn_stance`, `stacked_shooting_line` trait |
| Loading | waist/below-belly-button dip 뒤 two-hand delivery | `low_dip`, `two_hand_delivery` trait |
| Rhythm | delivery부터 release까지 pause가 거의 없는 extreme one-motion, 약 0.4초 release로 설명 | `continuous_one_motion`, `quick_release` qualitative cue |
| Ball / elbow path | shortest direct path, right elbow의 forward/upward push, rim 방향 alignment | `direct_elbow_drive`, `linear_target_path` trait |
| Wrist / guide hand | delivery의 안정적 wrist, palm rotation, guide hand가 release 직전까지 stability 제공 | `stable_wrist`, `late_guide_hand_release` cue |
| Finish | high one-hand follow-through, arm이 target 방향으로 끝남 | `high_direct_follow_through` trait |

## 사용 경계

이 profile은 narrative·2D form comparison copy 또는 feature-level recommendation explanation에만 쓸 수 있다. 원본 시리즈는 여러 broadcast/practice/instruction clip을 편집해 만든 single-camera reference이며, synchronized frame correspondence, calibration target, camera intrinsics/extrinsics, metric body scale을 제공하지 않는다. 따라서 해당 콘텐츠를 16-joint coordinate trajectory나 Curry의 calibrated 3D skeleton로 전환하지 않는다.
