# 팔로우스루 손목·팔꿈치 높이 보정

## 결함

기존 참조 애니메이션은 릴리스 손목이 어깨보다 약 0.22 단위만 높았고, 팔로우스루 높이도 손목이 어깨 위에 머무른다는 최소 조건만 검사했다. 이는 슈팅 참조 모션으로 부적절했다.

## 보정 기준

| 단계 | 손목 최소 높이 | 팔꿈치 최소 높이 | 추가 조건 |
| --- | ---: | ---: | --- |
| 릴리스 | 어깨 + 0.58 | 어깨 + 0.22 | 손목이 명확히 어깨선 위 |
| 팔로우스루 | 어깨 + 0.66 | 어깨 + 0.22 | 손목이 머리선 - 0.08 이상, 전방 연장 유지 |

`releaseWristLift`와 `followWristLift`를 분리해, 상승량이 팔로우스루에서 감소하더라도 슈팅 손목이 높게 유지되도록 수정했다. 16개 익명 참조 모두 새 품질 게이트를 통과했고, 웹 iPhone 폭에서 `모션 08 · 팔로우스루`를 직접 선택해 손목이 머리선 위로 올라간 것을 확인했다.

이 보정은 생체역학 참조 애니메이션의 표시 품질에 한정된다. 특정 선수의 계측 관절 경로를 주장하지 않는다.
